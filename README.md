# 海象模擬台

在瀏覽器裡即時運算的寫實海洋模擬，純前端、無後端，可直接用 GitHub Pages 部署。

## 功能
- **天氣與氣象**：時間（含時間倍率）、月相、風速風向、雲量、降水、氣溫、霧、雷暴
- **五種水域**：開放大洋、熱帶珊瑚海、極地海域、近岸港灣、高山湖泊，各有專屬遠景
- **海象奇觀**：丁達爾光、彩虹、綠閃光、海市蜃樓、日暈、極光、藍眼淚、浪花水霧、雨滴漣漪
- **天災**：海嘯、海底地震、漩渦、水龍捲、颱風、瘋狗浪；漁船可能翻覆
- **視角**：環視、登船、潛水（水下光柱、斯涅耳窗）

## 執行
任何靜態伺服器都可以，例如：

```
python3 -m http.server 8000
```

開啟 http://localhost:8000 。需要支援 WebGL2 的瀏覽器。

## 素材來源
- 月球表面：NASA Scientific Visualization Studio, CGI Moon Kit（LRO，公有領域）
- 漁船、浮標：Tripo 生成 3D 模型
- 遠景地平線：Codex 生成
